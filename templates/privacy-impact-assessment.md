# Privacy Impact Assessment (PIA) - template

A Privacy Impact Assessment (PIA) is a structured analysis of how a project, system or
initiative handles personal information against the Australian Privacy Principles and
related obligations. The OAIC recommends a PIA for any project with significant privacy
implications. For Commonwealth agencies, the Privacy (Australian Government Agencies -
Governance) APP Code 2017 requires a threshold assessment for high-privacy-risk
projects.

This template is the working version. A working example is at
[`../skills/privacy-act-apps/examples/pia-outline-customer-portal.md`](../skills/privacy-act-apps/examples/pia-outline-customer-portal.md).
