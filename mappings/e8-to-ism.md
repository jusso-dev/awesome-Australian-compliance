# Essential Eight to ISM mapping

This table maps each Essential Eight mitigation strategy to the ISM guideline groups
that hold most of the related controls. Specific control identifiers change between ISM
releases; the mapping is at the guideline level for that reason.

When producing an SSP or SoA, use this table to find the right guideline page, then open
the live ISM to pull the specific control identifiers and wording.

## Mapping table

| Essential Eight strategy | Primary ISM guideline groups | Secondary ISM guideline groups |
| --- | --- | --- |
| Application control | System Hardening, System Management, System Monitoring | Software Development, Media |
| Patch applications | System Management, System Hardening, Software Development | Procurement and Outsourcing, Cyber Supply Chain Risk Management |
| Configure Microsoft Office macro settings | System Hardening, Email | System Monitoring |
| User application hardening | System Hardening, Email | System Monitoring, Networking |
| Restrict administrative privileges | System Management, Personnel Security, System Hardening | System Monitoring, Cyber Security Roles |
| Patch operating systems | System Management, System Hardening, Networking | Procurement and Outsourcing |
| Multi-factor authentication | System Hardening, System Management, Cryptography | System Monitoring, Email |
| Regular backups | System Management, Physical Security, Cryptography | Cyber Security Incidents |

## How the mapping helps in practice

- Evidence collected for one Essential Eight strategy often satisfies multiple ISM
  controls in the listed guidelines. Use the mapping to avoid producing duplicate
  evidence.
- Conversely, ISM controls extend beyond the Essential Eight. An SSP that lists only
  E8-mapped controls is incomplete.
- The ACSC publishes Essential Eight assessment guidance that references ISM controls
  directly; pull both documents in any assessment.
