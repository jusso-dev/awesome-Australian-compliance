# PSPF Policy 2 - Management structures and responsibilities

This policy sets the management arrangements for protective security: the appointment
of a Chief Security Officer (CSO), supporting security roles and the lines of
responsibility.

Note: numbering and content may have shifted in the PSPF 2024 redesign. Confirm against
the live release.

## In plain English

Designate the people who run security day to day. Document their roles. Resource them.

## Key requirements

- Appoint a Chief Security Officer with appropriate authority.
- Establish supporting security roles (information security, personnel security,
  physical security).
- Define responsibilities and decision rights.
- Resource the security function to deliver the security plan.

## Evidence

- Position descriptions for the CSO and supporting roles.
- Security function organisation chart.
- Budget allocation to security.
- Skills and training records for the security team.

## Where to look

- Agency organisation chart.
- HR system records for security roles.
- Internal handbook describing security responsibilities across the agency.

## Common pitfalls

- CSO role doubled with another role (e.g. CIO) without enough time or authority for
  either.
- Security function under-resourced relative to the risk tolerance approved by the
  accountable authority.
- Information security and physical security operating in silos.
