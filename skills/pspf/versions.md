# PSPF versions

The PSPF has been substantially redesigned over its life. The most notable recent
redesign was in 2024, which reorganised the policy set and refreshed the maturity model
and reporting expectations.

When citing a PSPF requirement, name the release year. Example: `PSPF Policy 8 (PSPF
2024)`.

## Release register

| Release | Status | Notes | Last verified |
| --- | --- | --- | --- |
| PSPF 2024 redesign | unverified (treat as current) | The most recent substantive redesign. Reorganised the policy structure and updated the maturity model. Confirm the live policy numbering on protectivesecurity.gov.au before quoting specific policies. | TODO(source) |
| PSPF 2018 (pre-redesign) | superseded | The original 2018 structure with 16 numbered policies under four outcomes. Most long-running agency artefacts (older SSPs, older agency security plans) reference this version. | TODO(source) |
| Pre-2018 PSPF | superseded | Earlier PSPF iterations. Rarely encountered in active documents. | TODO(source) |

Status values:

- `current` - the live PSPF as of the last-verified date.
- `superseded` - a version no longer current but still cited in older artefacts.
- `unverified` - the entry exists but a maintainer has not opened the release page to
  confirm the structure. Do not quote policy numbers from an unverified release.
- `withdrawn` - explicitly withdrawn by AGD (rare).

## How an agent should use this register

- Ask which version applies. Default to the most recent `current` entry when the user
  does not specify.
- When comparing an existing artefact written under PSPF 2018 to the current PSPF,
  walk the policy mapping carefully; policy numbers and topic boundaries have moved.
- AGD publishes guidance documents alongside the PSPF. When refreshing artefacts to
  the current version, read both the policy text and the guidance.
